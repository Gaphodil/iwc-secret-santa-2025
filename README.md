# an evening stroll

This is the source code for a platforming-centric [fangame](https://cwpat.me/fangames-intro) I made for the I Wanna Community Secret Santa event, made during 2025-12-01 to 2025-12-24, for my assigned recipient, frostcolonthree, and can be downloaded [here](https://gaphodil.itch.io/iwc-secret-santa-2025). [This repo](https://github.com/Gaphodil/iwc-secret-santa-2025) is incomplete in terms of assets, but a full version containing the missing images and cut, volume-balanced audio files can be downloaded [here](https://drive.google.com/file/d/19sGj8zmHfKf7Hz1C6VoLougaeEBp-sr6).
